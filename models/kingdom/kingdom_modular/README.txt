Kingdoms of the Unknown — automatic modular terrain export

These are independent GLB files extracted from the uploaded terrain_kingdoms(2).glb.
Each preserves original node transforms and uses embedded materials and textures.
The base_ground_camera.glb contains Playable_Area and Camera.
Load base_ground_camera.glb first, then buildings and surroundings in batches.
Do not load every GLB simultaneously on iPhone.
NOTE: Some embedded textures are duplicated across GLBs; modularization alone does not guarantee lower final GPU memory usage.
The live GitHub game has NOT been modified by this export.

Keep textures optimized for mobile: 4096px maps reduced to 2048px; JPEG quality 82.
